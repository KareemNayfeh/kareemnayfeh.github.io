# Magnetic springs blog source package

Place this folder in your project, for example at `docs/magnetic-springs-source/`.

Start with `magnetic-springs-reference.md`. It contains the technical reference, page-level explanations, equations, limitations, and suggested blog outline. The `slides/` directory contains all 32 slide images, and `original-presentation.pdf` preserves the original.

Suggested prompt for Codex:

> Read docs/magnetic-springs-source/magnetic-springs-reference.md and inspect the linked slide images where needed. Use this material to create a clear technical blog post in this project's existing blog format. Explain the motivation, energy-based modeling approach, configurations, experimental results, and limitations. Preserve attribution and distinguish measured results from simulations and estimates. Do not invent personal contributions, data, or references. Follow the project's existing conventions for frontmatter, equations, images, and styling.

Change the path in the prompt if you place the folder elsewhere. The Markdown can also be used by itself, but the full package preserves the visual source material.
